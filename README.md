# Mashup Matchmaker

Every mashup and DJ tool out there helps you *execute* a mix once you've already
picked two songs — stem separation, beatmatching, transitions. Nobody helps you
figure out **which two songs to try in the first place**, which is usually the
actual bottleneck: hours of trial and error in Serato or Ableton before you even
start mixing. Mashup Matchmaker solves that earlier problem.

A web platform — type in song names directly in the browser, no installs, no
uploads.

## Features

- **Two-song compatibility check** — enter any two tracks and get an instant
  0–100 score based on tempo closeness and harmonic key matching, using the same
  Camelot wheel system professional DJs use to plan sets
- **Playlist mode** — paste in a whole playlist and get every possible pair
  ranked, so you find your best mashup candidates automatically instead of
  testing songs one at a time
- **Real music data, not guesses** — pulls actual tempo and key information from
  a database of millions of tracks
- **Gets smarter over time** — every search builds the platform's own dataset,
  so repeat lookups get instant and the tool needs external data less over time
- *(planned)* Analyze your own unreleased tracks directly when they're not in
  any public database

Song tempo/key data provided by [GetSongBPM](https://getsongbpm.com).

Built to explore a genuinely unsolved problem in mashup and DJ culture — with an
eye toward becoming a real tool for that community.
